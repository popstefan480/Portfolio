STEFAN PORTFOLIO - QUICK START

1. Open this folder in VS Code.
2. Open index.html in your browser (or use Live Server).
3. In index.html, search for YOUR- and replace:
   - YOUR-USERNAME
   - YOUR-PULSE-LIVE-DEMO
   - YOUR-PULSE-GITHUB-URL
   - YOUR-DATA-GITHUB-URL
   - YOUR-EMAIL@example.com
4. Change the site colors at the very top of style.css under :root.
5. When ready, create a new GitHub repository for this portfolio and upload index.html, style.css, script.js, and the images folder.

Main color variables:
--bg = background
--surface = cards
--text = main text
--muted = secondary text
--accent = accent/highlight color
--border = borders
